# 📈 onePercent Diary

**onePercent Diary** is a React-based web application built with Vite. It is designed to help you build unbreakable habits and unstoppable momentum by simply becoming 1% better than you were yesterday. Keep a daily track of your goals, time spent, and descriptions of what you learned or achieved.

🌐 **Live Demo:** [one-percent-diary.netlify.app](https://one-percent-diary.netlify.app)

## ✨ Features

- **Daily Tracking:** Track your daily goals, estimated time spent, and a brief description of your progress.
- **Grid Navigation:** Navigate through your days effortlessly with a 30-day pagination system.
- **Data Persistence:** Built-in support for saving progress locally and ready for Firebase Firestore integration.
- **Export Data:** Easily export your entire diary progress into a `.json` format for safekeeping.
- **Custom Styling:** Styled using [FantaCSS](https://github.com/jamezmca/fantacss), giving it a clean, readable, and responsive fantasy-inspired UI.

## 🧠 The Rules of 1% Growth

As featured in the app, follow these principles for massive long-term success:
1. **Never miss twice:** If you slip up one day, get back on track the very next day.
2. **The 2-Minute Rule:** Scale down your new habit so it takes two minutes or less to do.
3. **Focus on the system:** Fall in love with the daily process rather than just the final goal.
4. **Track your progress:** Keep a visual record of your streaks to build unbreakable momentum.

## 🚀 Tech Stack

- **Framework:** [React](https://reactjs.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Database:** [Firebase Firestore](https://firebase.google.com/)
- **Styling:** [FantaCSS](https://www.fantacss.smoljames.com/) & standard CSS

## 🛠️ Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Node.js installed on your machine.
* npm
  
```sh
  npm install npm@latest -g
```

## Installation
### Clone Repository
```sh
  git clone [https://github.com/Hirakaze/onepercent-diary.git](https://github.com/Hirakaze/onepercent-diary.git)
```
### Navigate to the project directory
```sh
  cd onepercent-diary
```
### Install NPM packages
```sh
  npm install
```
### (Optional, the code is commented!) Create a .env file in the root directory and add your Firebase configuration:
```sh
  VITE_FIREBASE_API_KEY=your_api_key
  VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
  VITE_FIREBASE_PROJECT_ID=your_project_id
  VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
  VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
  VITE_FIREBASE_APP_ID=your_app_id
```
### Start the development server
```sh
  npm run dev
```
